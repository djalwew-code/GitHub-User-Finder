# GitHub User Finder

## Автор
Свирина Ирина

## Описание
GUI-приложение для поиска пользователей GitHub с возможностью сохранения избранных пользователей. Приложение использует GitHub API для получения информации о пользователях и предоставляет удобный интерфейс для работы с данными.

## Функциональность
- Поиск пользователей GitHub по имени пользователя
- Отображение результатов поиска в виде списка
- Детальная информация о выбранном пользователе
- Добавление пользователей в избранное
- Сохранение избранных пользователей в JSON файл
- Просмотр и управление списком избранных пользователей
- Валидация ввода (проверка на пустое поле поиска)

## Требования
- Python 3.7 или выше
- Установленные зависимости из requirements.txt
